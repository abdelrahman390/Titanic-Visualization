# 🚢 Titanic Data Visualization Exercises

A hands-on data visualization project exploring the Titanic dataset through a variety of charts and visualization techniques using **Matplotlib, Seaborn, and Plotly**.

The project covers:
- **Univariate Analysis:** Histograms, KDE, box plots, bar charts, and pie charts.
- **Bivariate Analysis:** Survival rates, scatter plots, correlation heatmaps, and categorical comparisons.
- **Multivariate Analysis:** Pair plots, facet grids, treemaps, sunburst charts, bubble charts, and stacked bars.
- **Chart Selection:** Choosing appropriate visualizations and identifying misleading charts.
- **Data Insights:** Exploring the factors associated with passenger survival.

**Goal:** Develop practical data visualization skills and learn how to communicate meaningful insights through effective charts.
